Build a premium, modern, mobile-first Hotel / Restaurant Digital Menu website using Next.js.

IMPORTANT:
This is a DIGITAL MENU DISPLAY website.

Customers scan a QR code at a hotel table / restaurant / room and open this website.

The customer can:
- View the menu
- Search menu items
- Browse categories
- View food details
- See prices
- See availability
- See ratings and reviews
- Submit food reviews
- Rate the serving person
- Rate the restaurant/service

The customer CANNOT:
- Place an order
- Add items to cart
- Checkout
- Make payment
- Track an order

DO NOT CREATE:
- Cart
- Checkout
- Payment
- Order management
- Delivery tracking

The website should feel like the restaurant menu UI shown in the provided reference image.

==================================================
QR CODE ENTRY
==================================================

Customers enter the website through a QR code.

Example URL:

/menu/{qr_token}

Example:

/menu/table-a8f93kdh2

When the page opens:

1. Read the QR token from the URL.
2. Request menu data from FastAPI.
3. Load the restaurant information.
4. Load active banners.
5. Load categories.
6. Load menu items.
7. Load availability.
8. Load ratings.

Do not require customer login.

==================================================
REAL-TIME AVAILABILITY
==================================================

Connect the frontend to the FastAPI WebSocket.

WebSocket:

/api/v1/ws/menu/{qr_token}

When backend sends:

{
    "event": "MENU_ITEM_AVAILABILITY_CHANGED",
    "data": {
        "menu_item_id": 12,
        "is_available": false
    }
}

Immediately update the corresponding food card.

Example:

AVAILABLE

changes automatically to:

OUT OF STOCK

without refreshing the page.

Also handle:

MENU_ITEM_CREATED
MENU_ITEM_UPDATED
MENU_ITEM_DELETED
CATEGORY_UPDATED
BANNER_UPDATED

Use TanStack Query cache updates where appropriate.

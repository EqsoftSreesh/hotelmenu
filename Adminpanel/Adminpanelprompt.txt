Build a modern, responsive Admin Panel for a Hotel / Restaurant Digital Menu Management System.

IMPORTANT:
This is NOT an online ordering admin panel.

There is:
- No order management
- No cart
- No payment
- No checkout
- No delivery management

The admin panel is only for managing the digital menu, banners, availability, QR codes, staff, reviews and ratings.

==================================================

==================================================

Frontend:
- Next.js 15+
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod
- TanStack Query
- Axios
- Lucide React icons

Use a clean professional dashboard design.

The UI should be responsive for:
- Desktop
- Laptop
- Tablet
- Mobile

Use reusable components.

Do NOT hardcode menu data.

All data must come from the FastAPI backend.

==================================================
LIVE UPDATES
==================================================

Connect the admin panel to the FastAPI WebSocket.

When an admin changes:

- Menu availability
- Menu item
- Category
- Banner

the backend sends a WebSocket event.

The admin UI should update automatically.

Example event:

{
    "event": "MENU_ITEM_AVAILABILITY_CHANGED",
    "data": {
        "menu_item_id": 12,
        "is_available": false
    }
}

Use this to update the TanStack Query cache.

IMPORTANT UI REQUIREMENT
==================================================

The admin panel must NOT contain hardcoded data.

For example:

Wrong:

const menuItems = [
    {
        name: "Pasta",
        price: 14.99
    }
]

Correct:

const { data } = useQuery({
    queryKey: ["menu-items"],
    queryFn: getMenuItems
})
